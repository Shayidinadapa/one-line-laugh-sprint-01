A tiny Node program for the [One-Line Laugh Sprint](https://make.fun/bounty/u-daring-gecko-25-one-line-laugh-sprint-cda708b2) bounty on make.fun.

It writes one original funny line about everyday life — a smart speaker, a bank balance, and a whisper — to `/output/entry.txt`. The joke is written fresh for this bounty: no copied lines, no house texts, just one line with its twist saved for the last word.

## Run

```sh
node main.ts
```

It creates `/output` if needed and writes the line to `/output/entry.txt` (one line, under 200 characters, no trailing newline).
